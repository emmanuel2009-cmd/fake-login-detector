🔐 Fake Login Detector - Cybersecurity Tool Suite

📌 Overview
This project is a Python-based cybersecurity simulation tool that demonstrates login systems, password hashing, brute-force detection, and user account storage.

🚀 Features
- User account creation system
- Secure login authentication
- Password hashing (SHA-256)
- Persistent storage using JSON file
- Brute-force attack detection
- Security alerts and system blocking
- Login attempt logging system

🧠 Cybersecurity Concepts
- Authentication systems
- Password hashing
- Intrusion detection basics
- Rate limiting simulation
- Security logging

⚙️ How to Run
Run the program using:

python main_cli.py
